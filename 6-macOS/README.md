# Özbekça (yangi alifbo) — macOS klaviaturasi

Oddiy AQSh (QWERTY) klaviaturasi + yangi harflar **Option** tugmasi bilan:

| Tugmalar | Natija |
|---|---|
| Option + O / G / S / C | ö ğ ş ç |
| Shift + Option + O / G / S / C | Ö Ğ Ş Ç |
| Option + ' | ʼ (tutuq: maʼno) |
| Shift + Option + ' | ʻ |

CapsLock yoqiq bo'lsa, Option + O ham katta Ö beradi.

## O'rnatish

1. `Ozbekca-macOS.zip` ni oching — ichida `Ozbekca.bundle` bor.
2. Finder'da **Go → Go to Folder…** (⇧⌘G) → `~/Library/Keyboard Layouts` → `Ozbekca.bundle` ni shu papkaga torting.
   (Barcha foydalanuvchilar uchun: `/Library/Keyboard Layouts`, administrator paroli so'raladi.)
3. Tizimdan chiqib qayta kiring (Log Out) yoki Mac'ni qayta yoqing.
4. **System Settings → Keyboard → Text Input → Input Sources → Edit… → +** → ro'yxatdan
   **Uzbek** yoki **Others** ichidan **«Özbekça (yangi alifbo)»** ni qo'shing.
5. Til almashtirish: menyu satridagi til belgisi yoki **Ctrl + Space** / **🌐 Fn**.

Agar macOS "noma'lum dasturchi" deb ogohlantirsa — bu klaviatura fayli dastur emas, faqat tugmalar jadvali.

## O'chirish

`~/Library/Keyboard Layouts/Ozbekca.bundle` ni o'chiring va qayta kiring.
